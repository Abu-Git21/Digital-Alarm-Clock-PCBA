# Digital Alarm Clock PCBA

## Overview

This project involves the design and implementation of a digital alarm clock printed circuit board assembly (PCBA) as part of a university course. The project focuses on embedded systems, microcontroller programming, circuit design, and hardware integration.

**Code Attribution:** The source code for this project was provided as part of the course. I did not write the original code. My work involved completing the assigned laboratory exercises and working with the provided implementation.

## Concepts Demonstrated

* Embedded Systems
* Printed Circuit Board Assembly (PCBA)
* Microcontroller Integration
* Digital Electronics
* Circuit Design
* Hardware Debugging
* Embedded Programming
